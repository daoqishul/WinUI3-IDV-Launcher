IDV 启动器 v1.0.5 · WinUI 3 + 登录引擎
==========================================

原生 WinUI 3（Windows App SDK 1.8 / .NET 8）单窗口启动器。
账号管理直接读取原版 IDV-Login 的渠道账号，支持渠道服筛选和“登录账号”。

运行
----
双击 IdvLauncher.exe。Release 版需要管理员权限（UAC）。
支持跟随系统/深色/浅色、全局云母/全局亚克力/纯色、圆角/直角。

重要：本启动器不包含原版 IDV-Login 引擎。
请先安装原版 IDV-Login，默认路径：
  D:\ProgramData\IDV-Login
需要存在：
  python-embed\python.exe
  src\main.pyc
请保持默认安装路径；启动器会自动检测并在后台启动登录服务，不再显示目录/端口配置。

首次使用
--------
1. 阅读并同意免责声明；在设置中确认游戏路径。
2. 点“账号管理” → “添加渠道账号”，选择渠道服，在打开的渠道网页完成登录。
3. 完成后账号会写入 channels-v2.json；用顶部“全部渠道”下拉筛选。
4. 点账号右侧“登录账号”按该渠道登录。

新版发烧平台
------------
原版引擎通过 fever_bridge 模拟网易发烧平台 IPC，而不是直接改游戏文件。
本启动器现在通过引擎的 start-game API 启动游戏，会执行 Game.start，
自动激活 FeverBridge，让游戏使用内置登录界面，绕过新版发烧平台绑定。
不要直接启动 dwrg.exe，否则不会激活该桥接。

“登录账号”行为
---------------
- 将该账号 UUID 写入 config.json 的 auto-h55；
- 停止并重启登录引擎，让默认账号生效；
- 通过引擎托管启动游戏，由引擎按渠道完成登录。
如果游戏已经在运行，请先关闭游戏，再点“登录账号”。
这是“重启引擎 + 启动游戏”式切换，不是游戏内即时切换。

系统要求
--------
- Windows 10 1809 或更高版本
- .NET 8 Desktop Runtime
- Windows App Runtime 1.8
- 原版 IDV-Login
- 管理员权限

数据
----
启动器设置：%LOCALAPPDATA%\IDVLauncher\settings.json
引擎配置：  C:\ProgramData\idv-login\config.json
渠道账号：  C:\ProgramData\idv-login\channels-v2.json
引擎日志：  C:\ProgramData\idv-login\log.txt

说明
----
- 账号列表、添加（渠道网页）、改名、删除、默认账号、登录账号都在启动器内完成，不再打开原版账号管理界面。
- 首页公告使用 id5.163.com 官方源；首页封面为 Assets\51.jpg。
- 启动器打开后自动、隐藏启动登录服务，用户无需再点“启动引擎”；设置里不再显示引擎目录/代理端口。
- 首页账号区上方显示登录服务状态，未启动/失败时可手动点“启动登录服务”重试。
- 引擎启动改为 250ms 轮询并探测本地 HTTPS 健康接口，加快就绪速度。
- 首次打开软件有免责声明，不同意直接退出；设置里可再次查看。
- 首次打开解帧页需要填写“我同意并且后果自负封号由我来承担”；可点「一键填写同意」自动写入；不同意回到主页，页面常驻红色警告。
- 设置支持颜色模式（跟随系统/深色/浅色）、全局云母/全局亚克力/纯色、圆角/直角。
- 默认记住上次窗口大小/位置、侧边栏和页面；关闭“记住窗口大小”后每次固定 1268×690。
- 设置内“小托盘”：关闭窗口隐藏到系统托盘，双击显示，右键退出。
- 左侧「云存档」页：原版加密云同步，支持上传/下载/双向同步/自动同步/删除云端。
- 首页「启动游戏」：游戏运行中变为「关闭游戏」；登录服务未就绪时禁止启动。
- 「启动后最小化」默认关闭。
- 「登录引擎 → 游戏与启动」只保留只读游戏路径，已移除启动按钮、说明和原版账号列表。
- 左侧「解帧」页：开关 + 目标帧率（上限 500），调用 Tools\解帧.exe；需要游戏运行和管理员权限。
- 解帧工具使用隐藏真实控制台注入列表 ID/帧率，修复重定向输入、PID/ID 混淆和 Unicode 控制台读取导致的超时。
- 关闭窗口会立即隐藏界面，登录服务在后台停止和清理，不再等待 15 秒才消失。
- 解帧工具随包提供：Tools\解帧.exe。
- 账号管理的收藏账号会同步到首页；自动扫码登录开启时直接登录，关闭时可在游戏内置窗口手动选号。
- 设置内可编辑游戏画质/全屏/高帧率，以及原生键位编辑器（按动作分类修改按键）。
- 账号页星标即默认账号：取消星标会清空 auto-h55，不会自动登录。
- 安装包会请求管理员 UAC，安装向导为简体中文深色模板，默认安装到 Program Files。
- 安装时会显示“选择目标位置”，可自行选择安装目录。
- 安装包内置原版 IDV-Login 引擎到 `engine\IDV-Login`，无需另行安装登录引擎。
- 设置内“下载游戏”打开 PC 互通版页面；设置和 exe 图标使用 777.png。
- 设置内的“想要更新快一点？来赞助吧！”下拉菜单可展开显示赞助码。
- 原生添加/改名/删除在引擎运行时走本地 HTTPS API，需要引擎处于兼容模式（默认）；引擎未运行时改名/删除直接改 channels-v2.json。
- 部分渠道的网页登录会弹出渠道自己的登录窗口，这是渠道登录流程，不是原版账号管理器。
- 引擎会修改 hosts / NRPT / 证书 / 代理；正常停止/退出会清理，强杀可能残留。
- 请只使用自己的账号，遵守游戏用户协议。
- 本项目为非官方工具，与网易 / 第五人格官方无关。
- 如果引擎弹出版本更新/错误窗口，启动器等待 120 秒后会报超时；
  建议先单独运行一次原版工具完成更新。
